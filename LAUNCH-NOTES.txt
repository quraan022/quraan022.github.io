GitHub Pages setup:
1. Sign in to GitHub with the quraan022 account.
2. Create a new public repository named exactly: quraan022.github.io
3. Upload the contents of this outputs folder into the repository root. Do not upload the outputs folder itself.
4. Go to Settings > Pages.
5. Set Source to Deploy from a branch, branch main, folder /root.
6. Wait a few minutes, then open https://quraan022.github.io
