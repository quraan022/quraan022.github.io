SARA ABOZEINA – WEBSITE UPDATE PACKAGE
======================================
This package includes all 3 short MP4 teaching demos and a responsive teaching-portfolio.html page.
IMPORTANT: The public GitHub repository could be read but connector writes were blocked; these files have NOT been published yet.

To apply this package to a downloaded/cloned quraan022.github.io repository:
1. Extract this ZIP.
2. Ensure Python 3 is installed on the computer.
3. Run: python apply_site_update.py PATH_TO_SITE_FOLDER
4. Review index.html, qualifications.html, teaching-portfolio.html, testimonials.html in browser.
5. Upload/commit changed files and assets/videos in the quraan022.github.io GitHub repository.

Changes: independent 3-demo page, references to CV/qualifications/ijazahs, removal of unverified homepage counts and placeholder testimonials, removal of decorative percentage labels (PDF certificates preserved), removal of Testimonials navigation links in favor of Teaching Portfolio.

The ijazahs.html source had no embedded Ijazah photos, so no Ijazah photos are included in this package or removed from the source.
Note: the 3 videos total ~27 MB. If GitHub Pages bandwidth becomes a concern, use a publicly shared Drive or YouTube link instead.
